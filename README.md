# Weather App

Minimal Next.js weather app with live condition-based backgrounds.

## Quick start
1. Install deps: `npm install`
2. Create `.env.local` from `.env.local.example` and set `NEXT_PUBLIC_WEATHER_API_KEY`.
3. Run dev: `npm run dev` then open http://localhost:3000.

## Build & deploy
- Build: `npm run build`
- Start production build locally: `npm start`
- Deploy by pushing to GitHub and hosting on Vercel (recommended).
